# Go 1.26 升级实现计划

## 任务 1：升级版本声明与文档

**文件**
- 修改：`go.mod`
- 修改：`README.md`

**步骤**
1. 将模块的 `go` 版本提升到 `1.26.0`
2. 根据 Go 工具链行为决定是否保留显式 `toolchain` 行
3. 更新 README 中的 Go 版本徽标与安装说明

## 任务 2：补充端到端功能验证

**文件**
- 新增：`cmd/root_e2e_test.go`

**步骤**
1. 启动本地 `httptest` Web 服务，返回带标题和特征内容的页面
2. 通过测试进程调用 CLI 主命令扫描该本地服务
3. 校验输出中至少包含 URL、状态码、标题等核心字段
4. 保持测试不依赖外网

## 任务 3：在 Go 1.26 下整理依赖并验证

**命令**
- `GOTOOLCHAIN=go1.26.0 go version`

- `GOTOOLCHAIN=go1.26.0 go vet ./...`
